MY CARB, PROTEIN & FASTING TRACKER — VERSION 2

Features
• Food entries by TIME rather than breakfast/lunch/dinner
• Automatic current-time suggestion, editable before saving
• 18:6 fasting/eating-window display based on first and last food logged
• Total carbs, fiber, calculated net carbs, and protein
• Editable daily net-carb and protein goals
• Favorite foods / Quick Add
• Daily history
• Local-device storage
• JSON data backup/export
• No subscription or account required

NOTE: Default goals (50g net carbs and 80g protein) are placeholders only.
Change them in Goals & Settings to whatever targets you decide to use.

To install like an app, these files need to be hosted on an HTTPS website.
Once hosted, open it in Chrome on Android and choose Add to Home screen / Install app.
